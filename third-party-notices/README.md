The unchanged [MIT license](delegate-0.13.5/LICENSE-MIT) is retained here from [that exact source commit](https://github.com/kobzol/rust-delegate/blob/b129d4cbf4cc499eff7743365dcb0fe5d8d2e820/LICENSE-MIT), retrieved 2026-11-08.

SHA-256: `be7ee8aa49dc586023669a0c600a0536fce6a9f61264a53a67cdd842564ed899`.

This supplements release notices without modifying Cargo's registry source or checksum files. The release packager copies it to the matching package's license directory. It also retains upstream `AUTHORS` grants, including the MIT alternative distributed by `r-efi` in that file.

# LCD fixtures

- `protocol-native.bin` и `protocol-oracle.cpp`: actual оригинальный TT `Protocol.cpp`, QtCore6.8.3.512packet casesbyte-exact и169JPEGstructuraloutcomes/errorstrings. Include paths передаются macro при компиляции; подробный формат/sourcehash/команды в локальном `work/lcd-protocol/{REPORT.md,manifest.json}`. Проверка JPEG не декодирует entropy. Имитированный17-byteACK не доказывает аппаратный вывод.
- `two-frame.apng`: независимый syntheticPNG2×2, red100ms/blue200ms. Генератор `make-apng-fixture.py` использует только Pythonstdlib PNG chunks/zlib, запускается из корня репозитория. Нет пользовательских изображений, шрифтов или аппаратных ID.

Системный Segoe UI Black загружается локально в Windows tests/examples, файл шрифта не включён в репозиторий. Ограничения рендерера/подтверждения качества описаны в `PARITY.md`.
